`src/geometry.rs` has public items without documentation, so `cargo build` warns under `#![warn(missing_docs)]` and CI (which uses `-D warnings`) fails. Add a doc comment to every public item (the module, both structs, every public field and every function). Functions get a Google-shaped doc comment: a one-line summary, a blank line, then `# Arguments` listing each parameter and `# Returns`. Do not change any code.
