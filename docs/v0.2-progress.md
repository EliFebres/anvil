## Phase 1: factory cost fixes

### Plan

Step 1 (`anvil-types`, `factory-review`):

- `factory_config.rs`: optional `blocking` on `[[reviewers]]` (default true for correctness and safety, false for style and simplicity); validation needs at least one blocking reviewer; optional `[eval_gate] paths` (globs, validated); template comments.
- `factory-review`: `ReviewerId.blocking`; `Verdict::aggregate` sets every finding of a non-blocking reviewer aside as a comment; `review()` reruns only the failed reviewers up to two more times with a delay and keeps the delivered reviews; `Verdict.failed` names reviewers that still failed; `prompts/style.md` loses the "major because it fails the build" sentence (snapshot accepted).

Step 2 (`factory-core`, `factory-cli`, docs):

- `worker.rs`: order A, C, release build, B; Gate B skipped when no changed path matches `[eval_gate] paths`; a still-failed reviewer stops the ticket without an implementer run; per-gate cost records.
- `render.rs`: `fix_task` for review fix rounds; gate records with a skipped result; cost table in the pull request body.
- `status.rs`, `board.rs`, `ports.rs`: `GateCost` in `Outcome`, `OutcomeRecord` (`outcomes.jsonl`) and the dashboard snapshot; `Stage::ALL` in the new order.
- `factory-cli`: adapter passes tokens and failed reviewers through; `factory watch` snapshots; selftest label.
- `README.md`, `deploy/nuc/README.md`, `factory.toml`.

### Decisions

- Fix rounds use option (b): a fresh session whose task says the change is already on the branch, names the changed files and lists only the findings. Option (a) was not simpler: `anvil resume <id>` takes no new instruction and the factory does not capture the session id, so (a) would need changes in `anvil-cli` and the sandbox.
- A reviewer that still fails after its reruns pauses the ticket (`Outcome::Paused`): an unreachable review provider is the factory's failure, not the ticket's, the same reading as #12 took for container failures.
- The "do not undo an earlier round's fix" behavior stays where `acabdb3` put it: `earlier_findings` in the reviewer prompt.
